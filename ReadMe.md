# Quoc Thong Truong – Personal Website

This repository contains the source code for my personal website, hosted via **GitHub Pages**.

The website serves as my online portfolio and CV hub, showcasing my background, skills, projects and contact information for job opportunities.

## Live Website
Visit my live site here: [https://qttruong74.github.io/website/](https://qttruong74.github.io/website/)

## About
The website includes:
- **Home Page** – Introduction, projects, experience and education, skills and contact details.
- **CV Page** – View or download my CV in English and German (PDF).
- **Animated background** – A pixel-art circuit board that animates only while the mouse moves over it; when idle it shows a still image and does no redrawing (saves battery). The "PULSES" button turns the animation on or off completely.

## Built With
- **HTML5** – Structure of the pages.
- **CSS3** – Styling, layout, responsive design and print styles.
- **Vanilla JavaScript** – Canvas animation for the background (no libraries).
- **GitHub Pages** – Free hosting directly from the repository.

## Privacy
The site makes **no requests to third-party servers**. Fonts are self-hosted, so no data is sent to Google or any CDN.

## Project Structure
- `index.html` – Home page
- `cv.html` – CV page (English and German download)
- `style.css` – Global styles and self-hosted font declarations
- `board.js` – Animated circuit-board background
- `fonts/` – Self-hosted fonts with their license texts
- `CV_English.pdf`, `CV_German.pdf` – My CVs
- `CREDITS.md` – Sources and licenses of everything not written by me
